# .

Build a completely redesigned travel website called سفير المحبة for a Bahraini traveller named Ahmad.

The website documents Ahmad’s lifelong passion for travelling, the countries and cities he has visited, his personal stories, photographs, videos, cultural observations, and prepared travel itineraries.

Use the existing website as the complete source of truth:

https://100region.com/

Study the full website carefully, including its homepage, menus, continent pages, country pages, city pages, articles, photographs, videos, cultural content, travel itineraries, and personal stories.

Import and reuse the original content and images from the existing website wherever technically possible.

Do not copy the existing website’s design. The new website must have a completely new structure, visual identity, interface, and user experience.

Main objective

Transform Ahmad’s existing travel archive into a modern, elegant, interactive travel experience.

The website should feel like:

A personal travel journal

Ahmad must remain the central character of the website.

The experience should communicate:
